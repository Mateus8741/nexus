# entities

Entidades de domínio: objetos com identidade própria e ciclo de vida (ex.: `Ambiente`, `Espaco`, `Dispositivo`, `Usuario`).

Seguindo a visão do projeto (ver `PROJECT.md`), os nomes devem ser sempre genéricos — nunca amarrados a "casa" ou "residência".

Implementado até aqui: `device.ts` (`Device`, `DeviceCapability`).
